# Compatibility

WindBar 1.0 is currently planned for Windows 11 x64.

Public beta/release notes will document the supported Windows builds once the compatibility matrix is finalized.

The v1 goal is one WindBar taskbar on the primary monitor while remaining safe on multi-monitor systems, including mixed-DPI setups. Independent WindBar taskbars per monitor are currently post-v1.

Windows 10 support, ARM64-native support, and enterprise deployment are not current v1 commitments.
