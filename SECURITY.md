# Security

WindBar is shell-adjacent software, so reliability and safe recovery are treated as security-sensitive product qualities.

Until a dedicated private security-reporting channel is published, please avoid posting exploit details, secrets, or sensitive diagnostic data in public issues.

For ordinary crashes, compatibility problems, or recovery failures, use the public issue tracker and include only the minimum diagnostics needed to reproduce the problem.

Third-party/community content is not automatically endorsed or supported by WindBar. Officially distributed content will be clearly identified by the project.
