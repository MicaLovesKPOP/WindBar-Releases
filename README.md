# WindBar Releases

WindBar is a Windows 11 taskbar replacement project focused on a native-feeling, modular taskbar experience while keeping Explorer available as a safe fallback.

This public repository is the home for WindBar releases, release notes, compatibility information, known issues, and public issue tracking.

> WindBar is still in development. Public release builds will appear here when they are ready for testing.

## What belongs here

- Public WindBar release builds and release notes
- Compatibility and installation information
- Known issues and recovery guidance
- Bug reports, compatibility reports, and feature requests
- Public roadmap information

The main WindBar development repository is currently private.

## Community creations

Creator documentation, community experiments, and contributions considered for possible official integration belong in [WindBar-Contributions](https://github.com/MicaLovesKPOP/WindBar-Contributions).

## Current direction

WindBar's v1 target is a stable Windows 11 x64 taskbar replacement with all four taskbar edges, modular layout, normal application/taskbar workflows, Start and Search access, a usable notification area, Settings, auto-hide, safe recovery, and an optional official Media Player plugin.

See [ROADMAP.md](ROADMAP.md) for the public roadmap.
