# Contributing to WindBar Releases

This repository is for public release information, bug reports, compatibility reports, and feature requests.

The main WindBar development repository is currently private, so code contributions are not accepted here.

## Good issue reports include

- WindBar version/build
- Windows version/build
- Taskbar edge
- Monitor count and scaling values
- Clear reproduction steps
- What you expected to happen
- What actually happened
- Diagnostic information or logs when available

Please remove personal information from screenshots and logs before posting them publicly.

## Feature requests

Describe the user problem first, then the proposed solution. Requests may be classified as release-blocking, release-quality, or post-v1 depending on current priorities.

## Creator contributions

Themes, layouts, plugin concepts, Start content, and other creator-facing work belong in [WindBar-Contributions](https://github.com/MicaLovesKPOP/WindBar-Contributions).
